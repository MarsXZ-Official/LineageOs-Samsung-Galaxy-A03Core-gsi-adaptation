# 📘 **ПОВНИЙ ПОСІБНИК З FLASH GSI ЧЕРЕЗ ODIN 3.14.4 (Windows), ODIN4 (Linux) ТА HEIMDALL (Mac)**

Цей посібник підходить для всіх пристроїв Samsung з розблокованим завантажувачем та підтримкою Project Treble (GSI).

---

> ⚠️ **Відмова від відповідальності**
> **Ви виконуєте прошивку на свій страх і ризик. Автор цього посібника не несе відповідальності за будь-які пошкодження пристрою, втрату даних або несправність.**

---

## ✅ 1. Вимоги

* Пристрій Samsung з розблокованим завантажувачем
* ПК з Windows, Linux або macOS
* Odin (для Windows / Linux) або Heimdall (для macOS)
* USB-драйвери Samsung (для Windows)
* Якісний USB-кабель
* **Архів із файлами `super.img`** (і `boot.img`, якщо є) — завантажений GSI
* Рекомендується: пристрій заряджений щонайменше на 80%

> ⚠️ Увага: Під час завантаження GSI ви отримаєте **архів**. Його **не потрібно повністю розпаковувати** — дії залежать від вашої ОС:
> * **У Windows / Linux (Odin / Odin4)**: прошивайте файл `LineageOs20/21.tar` як є.
> * **У macOS (Heimdall)**: розпакуйте `LineageOs20/21.tar`, щоб витягти `boot.img` (якщо є) і `super.img` — саме їх потрібно прошивати.

## 🧰 2. Підготовка пристрою

### 2.1. Увімкнення параметрів розробника

1. Перейдіть у **Налаштування → Про телефон**.
2. Натисніть 7 разів на пункт **Номер збірки (Build number)**.
3. Поверніться назад, відкрийте **Параметри розробника** і увімкніть:
* **OEM Unlocking**
* **USB Debugging**

### 2.2. Розблокування завантажувача

> Переконайтеся, що телефон заряджений щонайменше на 80%.
> **Не підключайте USB-кабель!** Якщо він підключений — від’єднайте його, інакше пристрій перейде в режим заряджання.

1. Повністю вимкніть телефон і зачекайте 10 секунд.
2. Натисніть і утримуйте одночасно **Гучність вниз + Живлення**.
3. Коли з’явиться логотип Samsung, відпустіть кнопку **Живлення**, але продовжуйте утримувати **Гучність вниз** до появи синього екрана із попередженням.
4. **Підключіть USB-кабель** до ПК.
5. Виконайте **ДОВГЕ НАТИСКАННЯ Гучності вгору**, щоб увійти в режим розблокування (Device unlock mode).
6. Натисніть **Гучність вгору** один раз для підтвердження.
7. Пристрій очистить дані, розблокує завантажувач і автоматично перезавантажиться.

### 2.3. Скидання даних

*(Почекайте повного завантаження пристрою після розблокування, потім знову вимкніть його).* 

1. Увійдіть у Recovery (утримуйте **Гучність вгору + Живлення** під час увімкнення).
2. Виберіть **Wipe data / factory reset**.
3. Виберіть **Factory data reset** для підтвердження.

### 2.4. Вхід у Download Mode

1. Вимкніть пристрій.
2. Натисніть **Гучність вниз + Гучність вгору** і **підключіть USB-кабель**.
3. Коли з’явиться синій екран із попередженням, відпустіть кнопки.
4. Виконайте **КОРОТКЕ НАТИСКАННЯ Гучності вгору**, щоб увійти в Download Mode для прошивки.

## 🪟 3. Прошивка через Odin (Windows)

### 3.1. Завантаження та встановлення

* [Завантажити Odin (рекомендується 3.14.4)](https://github.com/MarsXz8656/LineageOs-Samsung-Galaxy-A03Core-gsi-adaptation/tree/system/%D0%9Edin)
* [Встановити Samsung USB Driver’и](https://developer.samsung.com/android-usb-driver)

### 3.2. Налаштування Odin

1. Запустіть Odin.
2. Підключіть пристрій → в логах має з’явитися повідомлення **Added!!**
3. Натисніть кнопку **AP** → виберіть **архів у форматі `.tar`**.
4. У вкладці **Options** переконайтеся, що галочки стоять лише на:
* **Auto Reboot**
* **F. Reset Time**

> ❌ **Не вмикайте:** Re-Partition або Nand Erase.

### 3.3. Запуск прошивки

Натисніть **Start** і дочекайтеся завершення (зазвичай 1–3 хвилини).

Якщо все пройшло успішно, верхня ліва клітинка загориться зеленим і з’явиться напис **PASS!**

### 3.4. Перевірка результату

Пристрій перезавантажиться автоматично.

* Якщо завантажилася система — GSI встановлена успішно.
* Якщо пристрій зайшов у bootloop (вічне завантаження) — зайдіть у Recovery і виконайте Wipe Data.

## 🐧 4. Прошивка через Odin4 (Linux)

### 4.1. Завантаження та налаштування

1. **Завантажте Odin4:**
Перейдіть на [сторінку релізів](https://github.com/MarsXZ-Official/LineageOs-Samsung-Galaxy-A03Core-gsi-adaptation/blob/system/%D0%9Edin/Linux/odin4) і завантажте файл `odin4`.
2. **Зробіть Odin4 виконуваним:**
Змініть права доступу до бінарного файлу через термінал:
```bash
chmod +x odin4
```

3. **Перемістіть odin4 до каталогу /bin:**
Щоб програма була доступна з будь-якої точки системи, виконайте:
```bash
sudo cp odin4 /bin
```

### 4.2. Процес прошивки

Запустіть прошивку за допомогою такої команди:

```bash
sudo odin4 -a ім’я_архіву.tar --reboot
```

**Розшифровка команди:**

* `sudo` — запуск від імені адміністратора (root)
* `odin4` — виклик самої програми
* `-a` — вказання прошивного розділу (AP)
* `ім’я_архіву.tar` — шлях до вашого `.tar` файлу
* `--reboot` — автоматичне перезавантаження після успішної прошивки

## 🍏 5. Прошивка через Heimdall (macOS)

### 5.1. Встановлення Heimdall

Відкрийте термінал і встановіть Heimdall через Homebrew:

```bash
brew install heimdall
```

### 5.2. Підготовка файлів

1. Ви завантажили архів `.tar` із GSI.
2. Розпакуйте його в терміналі:
```bash
tar -xf ім’я_архіву.tar
```

3. Усередині ви отримаєте один або два файли: `boot.img` (якщо передбачено) і `super.img`.
4. Перейдіть до каталогу з розпакованими файлами:
```bash
cd ~/шлях_до_розпакованих_файлів
```

### 5.3. Перевірка підключення

Переконайтеся, що пристрій знаходиться в **Download Mode** і підключений до Mac, потім введіть:

```bash
heimdall detect
```

Якщо термінал видав *Device detected* — пристрій готовий до прошивки.

### 5.4. Прошивка

Прошийте розділ `super`:

```bash
heimdall flash --super super.img
```

> **Примітка:** На деяких пристроях Samsung розділ може називатися `--super` або `--SUPER`. Якщо виникає помилка, спробуйте змінити регістр.

При необхідності, якщо в архіві був `boot.img`, прошийте й його:

```bash
heimdall flash --boot boot.img
```

### 5.5. Завершення та перевірка результату

Heimdall покаже прогрес виконання і автоматично перезавантажить пристрій.

* Пристрій завантажився → все пройшло успішно.
* Пристрій зайшов у bootloop → зайдіть у Recovery і виконайте Wipe Data.
* Помилка прошивки → перевірте сумісність завантаженого GSI з вашим пристроєм.
