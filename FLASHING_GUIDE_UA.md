# 📘 **ПОВНИЙ ПОСІБНИК З FLASH GSI ЧЕРЕЗ ODIN (Windows) ТА HEIMDALL (Linux/Mac)**

Цей посібник підходить для всіх пристроїв Samsung з розблокованим завантажувачем і підтримкою Project Treble (GSI).

---

# ⚠️ **Відмова від відповідальності**

**Ви виконуєте прошивку на свій страх і ризик. Автор цього посібника не несе відповідальності за пошкодження пристрою, втрату даних або bricking.**

---

# ✅ **1. Вимоги**

- Пристрій Samsung з розблокованим завантажувачем  
- ПК з Windows або Linux/Mac  
- Odin (для Windows)  
- Heimdall (для Linux/Mac)  
- USB-драйвери Samsung  
- USB-кабель  
- **Архів із файлами super.img** (і boot.img, якщо є) — завантажений GSI  
- Рекомендується: повністю заряджений телефон  

> ⚠️ Під час завантаження GSI ви отримаєте **архів**. Його **не потрібно розпаковувати повністю**, прошивати потрібно **тільки super.img** (і boot.img, якщо є) всередині архіву.

---

# 🧰 **2. Підготовка пристрою**

## **2.1. Увімкнути параметри розробника**

1. Налаштування → Про телефон  
2. Натисніть **Build number** 7 разів  
3. У меню розробника увімкніть:
   - **OEM Unlocking**  
   - **USB Debugging**

---

## **2.2. Розблокування завантажувача**

1. Вимкніть телефон  
2. Натисніть **Volume Down + Volume Up + підключіть USB**  
3. Натисніть **Volume Up** для підтвердження  
4. Пристрій видалить дані та розблокує завантажувач

---

## **2.3. Скидання даних**

1. Увійдіть у Recovery (**Volume Up + Power**)  
2. Виберіть **Wipe data / factory reset**

---

## **2.4. Вхід у Download Mode**

1. Вимкніть пристрій  
2. Натисніть **Volume Down + Volume Up + USB**  
3. Натисніть **Volume Up** для входу

---

# 🪟 **3. Прошивка через Odin (Windows)**

## **3.1. Завантаження та встановлення**

- Завантажте Odin (рекомендується 3.14.4)  
- Встановіть Samsung USB драйвери  

---

## **3.2. Налаштування Odin**

1. Відкрийте Odin  
2. Підключіть пристрій → має з’явитися **Added!!**  
3. Натисніть **AP** → оберіть `.tar` архів  
4. Залиште активними тільки ці параметри:
   - **Auto Reboot**  
   - **F. Reset Time**  

Не вмикайте:
- Re-Partition  
- Nand Erase  

---

## **3.3. Початок прошивки**

Натисніть **Start** в Odin і чекайте 1–3 хвилини.  
Якщо успішно — з’явиться **PASS!**  

---

## **3.4. Перевірка результату**

Пристрій автоматично перезавантажиться.  
Якщо він завантажився — GSI встановлено.  
Якщо bootloop — виконайте Wipe Data в Recovery.

---

# 🐧 **4. Прошивка через Heimdall (Linux/Mac)**

## **4.1. Встановлення Heimdall**

### Ubuntu/Debian:

```bash
sudo apt install heimdall-flash
```

### Arch Linux:

```bash
sudo pacman -S heimdall
```

### macOS (brew):

```bash
brew install heimdall
```

---

## **4.2. Підготовка файлів для прошивки**

1. Ви завантажили `.tar` архів із GSI.  
2. Розпакуйте його:

```bash
tar -xf archive_name.tar
```

3. Всередині буде один або два файли:  
   - **boot.img** (якщо є)  
   - **super.img**

4. Перейдіть у каталог із цими файлами:

```bash
cd ~/path_to_extracted_files
```

---

## **4.3. Перевірка підключення**

Пристрій повинен бути в **Download Mode**:

```bash
heimdall detect
```

Якщо Heimdall показує *Device detected* — готово до прошивки.

---

## **4.4. Прошивка super.img**

```bash
sudo heimdall flash --super super.img
```

> На деяких Samsung розділ може називатися `--super` або `--SUPER`.  
> Якщо виникла помилка — спробуйте обидва варіанти.  
> При потребі також можна прошивати **boot.img**:

```bash
sudo heimdall flash --boot boot.img
```

---

## **4.5. Завершення**

Heimdall покаже процес і автоматично перезавантажить пристрій.  

Після перезавантаження перевірте, що пристрій завантажився і GSI встановлено.

---

## **4.6. Перевірка успішної установки**

- Пристрій завантажився → все добре  
- Bootloop → виконайте Wipe Data  
- Помилка прошивки → перевірте сумісність GSI  

---

# 🎉 Готово!

**GSI встановлено і готово до використання.**
