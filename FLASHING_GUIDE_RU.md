# 📘 ПОЛНОЕ РУКОВОДСТВО ПО ПРОШИВКЕ GSI ЧЕРЕЗ ODIN (Windows), ODIN4 (Linux) И HEIMDALL (Mac)

Это руководство подходит для всех устройств Samsung с разблокированным загрузчиком и поддержкой Project Treble (GSI).

---

> ⚠️ **Дисклеймер**
>

## ✅ 1. Требования

* Устройство Samsung с разблокированным загрузчиком
* ПК с ОС Windows, Linux или macOS
* Odin (для Windows / Linux) или Heimdall (для macOS)
* USB-драйверы Samsung (для Windows)
* Качественный USB-кабель
* **Архив с файлами `super.img**` (и `boot.img`, если есть) — скачанный GSI
* Рекомендуется: устройство заряжено минимум на 80%

> ⚠️ **Внимание:** При скачивании GSI вы получите **архив**. Его **не нужно полностью распаковывать** — действия зависят от вашей ОС:
> * **На Windows / Linux (Odin / Odin4)**: прошивайте файл `LineageOs20/21.tar` как есть.
> * **На macOS (Heimdall)**: распакуйте `LineageOs20/21.tar`, чтобы извлечь `boot.img` (если есть) и `super.img` — именно их нужно прошивать.

## 🧰 2. Подготовка устройства

### 2.1. Включение параметров разработчика

1. Перейдите в **Настройки → О телефоне**.
2. Нажмите 7 раз по пункту **Номер сборки (Build number)**.
3. Вернитесь назад, зайдите в **Параметры разработчика** и включите:
* **OEM Unlocking** (Заводская разблокировка)
* **USB Debugging** (Отладка по USB)



### 2.2. Разблокировка загрузчика

> Убедитесь, что телефон заряжен минимум на 80%.
> **НЕ подключайте USB-кабель!** Если он подключен — отсоедините его, иначе телефон перейдет в режим зарядки.

1. Полностью выключите телефон и подождите 10 секунд.
2. Зажмите и удерживайте одновременно **Громкость вниз + Питание**.
3. Когда появится логотип Samsung, отпустите кнопку **Питания**, но продолжайте держать **Громкость вниз** до появления синего экрана с предупреждением.
4. **Подключите USB-кабель** к ПК.
5. Сделайте **ДОЛГОЕ НАЖАТИЕ Громкости вверх**, чтобы войти в режим разблокировки (Device unlock mode).
6. Нажмите **Громкость вверх** один раз для подтверждения.
7. Устройство очистит данные, разблокирует загрузчик и автоматически перезагрузится.

### 2.3. Очистка данных

*(Дождитесь полной загрузки устройства после разблокировки, затем снова выключите его).*

1. Зайдите в Recovery (зажмите **Громкость вверх + Питание** при включении).
2. Выберите **Wipe data / factory reset**.
3. Выберите **Factory data reset** для подтверждения.

### 2.4. Переход в Download Mode

1. Выключите устройство.
2. Зажмите **Громкость вниз + Громкость вверх** и **подключите USB-кабель**.
3. Когда появится синий экран с предупреждением, отпустите кнопки.
4. Сделайте **КОРОТКОЕ НАЖАТИЕ Громкости вверх**, чтобы войти в Download Mode для прошивки.

## 🪟 3. Прошивка через Odin (Windows)

### 3.1. Скачивание и установка

* [Скачать Odin (рекомендуется 3.14.4)](https://github.com/MarsXz8656/LineageOs-Samsung-Galaxy-A03Core-gsi-adaptation/tree/system/%D0%9Edin)
* [Установить Samsung USB Drivers](https://developer.samsung.com/android-usb-driver)

### 3.2. Настройка Odin

1. Запустите Odin.
2. Подключите устройство → в логе должно появиться сообщение **Added!!**
3. Нажмите кнопку **AP** → выберите **архив в формате `.tar**`.
4. Во вкладке **Options** убедитесь, что галочки стоят **только** на:
* **Auto Reboot**
* **F. Reset Time**



> ❌ **НЕ включайте:** Re-Partition или Nand Erase.

### 3.3. Запуск прошивки

Нажмите **Start** и дождитесь завершения (обычно 1–3 минуты).

Если всё прошло успешно, верхняя левая ячейка загорится зелёным с надписью **PASS!**

### 3.4. Проверка результата

Телефон перезагрузится автоматически.

* Если загрузилась система — GSI установлена успешно.
* Если устройство ушло в bootloop (вечная загрузка) — зайдите в Recovery и сделайте Wipe Data.

## 🐧 4. Прошивка через Odin4 (Linux)

### 4.1. Скачивание и настройка

1. **Скачайте Odin4:**
Перейдите на [страницу релизов](https://github.com/MarsXZ-Official/LineageOs-Samsung-Galaxy-A03Core-gsi-adaptation/blob/system/%D0%9Edin/Linux/odin4) и скачайте файл `odin4`.
2. **Сделайте Odin4 исполняемым:**
Измените права доступа к бинарному файлу через терминал:
```bash
chmod +x odin4

```


3. **Переместите odin4 в директорию /bin:**
Чтобы программа была доступна из любой точки системы, выполните:
```bash
sudo cp odin4 /bin

```



### 4.2. Процесс прошивки

Запустите прошивку, используя следующую команду:

```bash
sudo odin4 -a имя_архива.tar --reboot

```

**Расшифровка команды:**

* `sudo` — запуск от имени администратора (root).
* `odin4` — вызов самой программы.
* `-a` — указание прошиваемого раздела (AP).
* `имя_архива.tar` — путь к вашему `.tar` файлу.
* `--reboot` — автоматическая перезагрузка при успешной прошивке.

## 🍏 5. Прошивка через Heimdall (macOS)

### 5.1. Установка Heimdall

Откройте терминал и установите Heimdall через Homebrew:

```bash
brew install heimdall

```

### 5.2. Подготовка файлов

1. Вы скачали архив `.tar` с GSI.
2. Распакуйте его в терминале:
```bash
tar -xf имя_архива.tar

```


3. Внутри вы получите один или два файла: `boot.img` (если предусмотрено) и `super.img`.
4. Перейдите в каталог с извлеченными файлами:
```bash
cd ~/путь_к_распакованным_файлам

```



### 5.3. Проверка подключения

Убедитесь, что телефон находится в **Download Mode** и подключен к Mac, затем введите:

```bash
heimdall detect

```

Если терминал выдал *Device detected* — устройство готово к прошивке.

### 5.4. Прошивка

Прошейте раздел `super`:

```bash
sudo heimdall flash --super super.img

```

> **Примечание:** На некоторых устройствах Samsung раздел может называться `--super` или `--SUPER`. Если возникает ошибка, попробуйте изменить регистр.

При необходимости, если в архиве был `boot.img`, прошейте и его:

```bash
sudo heimdall flash --boot boot.img

```

### 5.5. Завершение и проверка результата

Heimdall покажет прогресс выполнения и автоматически перезагрузит устройство.

* Устройство загрузилось → всё прошло успешно.
* Устройство ушло в bootloop → зайдите в Recovery и сделайте Wipe Data.
* Ошибка прошивки → проверьте совместимость скачанного GSI с вашим устройством.
